# RAG - Chat with PDF

A simple RAG (Retrieval Augmented Generation) app that lets you upload any PDF and chat with it.

## Features
- Upload PDF file
- Extract text from PDF
- Split text into chunks
- Ask questions from PDF content

## Tech Stack
- Streamlit
- PyPDF
- LangChain Text Splitters

## How to Run
pip install -r requirements.txt
streamlit run app.py
